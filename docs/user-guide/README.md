## What is Video Import?

The Video Import feature allows you to:

- **Import videos** from YouTube, Instagram, Facebook, TikTok, and other platforms
- **Automatically transcribe** and translate video content
- **Detect highlights** using AI to create engaging short clips
- **Smart crop** videos to different orientations (portrait, landscape, square)
- **Add music and overlays** to create professional short-form content
- **Process multiple videos** simultaneously with batch import

## System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Stable internet connection for downloading videos
- The system supports videos up to 60 minutes in length
- Maximum file size: 10GB per video
