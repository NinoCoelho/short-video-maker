# TranslationService Documentation\n\n## Overview\n\nThe `TranslationService` is a comprehensive translation system designed to support the video import pipeline with advanced features for multi-language content creation, subtitle processing, and quality optimization.\n\n## Features\n\n### 🌐 Multi-Provider Translation Support\n- **Google Cloud Translate**: Enterprise-grade translation with high accuracy\n- **DeepL**: Premium translation quality, especially for European languages\n- **OpenAI GPT**: Context-aware translation with custom prompting\n- **Google Generative AI**: Powered by Gemini models\n- **Ollama**: Local/self-hosted translation for privacy-conscious deployments\n\n### 🎯 Smart Provider Fallback System\n- Automatic fallback to secondary providers if primary fails\n- Configurable retry logic with exponential backoff\n- Provider health monitoring and automatic switching\n\n### 📝 Comprehensive Subtitle Processing\n- **Format Support**: SRT, VTT, ASS/SSA subtitle formats\n- **Extraction**: Extract existing subtitles from video files\n- **Embedded Subtitles**: Support for extracting embedded video captions\n- **Bilingual Subtitles**: Generate dual-language subtitle files\n- **Style Customization**: Font, size, color, positioning options\n\n### 🧠 Advanced Language Detection\n- **Multi-Provider Detection**: Google Cloud, OpenAI-based detection\n- **Heuristic Fallback**: Pattern-based detection for 30+ languages\n- **Automatic Source Detection**: No need to specify source language\n\n### ⚡ Performance Optimizations\n- **Intelligent Caching**: Redis-compatible caching with TTL\n- **Batch Processing**: Translate multiple videos efficiently\n- **Context-Aware Translation**: Use surrounding segments for better accuracy\n- **Length Optimization**: Automatic text length adjustment for subtitles\n\n### 🎨 Quality Enhancement Features\n- **Terminology Consistency**: Preserve technical terms and brand names\n- **Cultural Adaptation**: Automatic unit conversion (°F/°C, miles/km, etc.)\n- **Glossary Support**: Custom term translations\n- **Style Adaptation**: Formal, casual, technical, creative translation styles\n\n### 💾 Persistent Storage & Management\n- **Translation Versioning**: Track multiple translation versions\n- **Metadata Storage**: Store translation metrics and settings\n- **Bulk Operations**: Import/export translation data\n- **History Tracking**: Complete audit trail for translations\n\n## Installation & Setup\n\n### Prerequisites\n\n```bash\nnpm install @google-cloud/translate deepl-node node-cache\n```\n\n### Environment Variables\n\nSet up your API keys in the environment:\n\n```bash\n# Google Cloud Translate\nexport GOOGLE_CLOUD_API_KEY=\"your-google-cloud-key\"\n\n# DeepL API\nexport DEEPL_API_KEY=\"your-deepl-key\"\n\n# OpenAI API\nexport OPENAI_API_KEY=\"your-openai-key\"\n\n# Google Generative AI\nexport GOOGLE_AI_API_KEY=\"your-google-ai-key\"\n```\n\n### Basic Initialization\n\n```typescript\nimport { TranslationService } from './services/TranslationService';\n\nconst apiKeys = {\n  googleCloud: process.env.GOOGLE_CLOUD_API_KEY,\n  deepl: process.env.DEEPL_API_KEY,\n  openai: process.env.OPENAI_API_KEY,\n  google: process.env.GOOGLE_AI_API_KEY\n};\n\nconst translationService = new TranslationService('./data', apiKeys);\n```\n\n## Quick options)`\nTranslates an array of transcript segments.\n\n**Parameters:**\n- `segments`: Array of `TranscriptSegment` objects\n- `options`: `TranslationOptions` configuration object\n\n**Returns:** `Promise<TranslationResult>`\n\n#### `extractSubtitles(videoPath)`\nExtracts existing subtitles from a video file.\n\n**Parameters:**\n- `videoPath`: Path to the video file\n\n**Returns:** `Promise<SubtitleExtractionResult>`\n\n#### `createSubtitlesFromTranscription(segments, format, outputPath, options?)`\nCreates subtitle files from transcript segments.\n\n**Parameters:**\n- `segments`: Array of transcript segments\n- `format`: 'srt' | 'vtt' | 'ass'\n- `outputPath`: Output file path\n- `options`: Optional formatting options\n\n**Returns:** `Promise<string>` (output path)\n\n#### `generateBilingualSubtitles(original, translated, format, outputPath, options?)`\nGenerates bilingual subtitle files.\n\n**Parameters:**\n- `original`: Original language segments\n- `translated`: Translated segments\n- `format`: Subtitle format\n- `outputPath`: Output file path\n- `options`: Formatting and layout options\n\n**Returns:** `Promise<string>` (output path)\n\n#### `batchTranslate(videos, options)`\nTranslates multiple videos in batch.\n\n**Parameters:**\n- `videos`: Array of video objects with segments and output paths\n- `options`: Translation options\n\n**Returns:** `Promise<TranslationResult[]>`\n\n### Storage Methods\n\n#### `saveTranslation(videoId, sourceLanguage, targetLanguage, segments, metadata?)`\nSaves translation to persistent storage.\n\n#### `loadTranslation(translationId)`\nLoads a translation from storage.\n\n#### `listTranslations(videoId)`\nLists all translations for a specific video.\n\n### Utility Methods\n\n#### `getAvailableProviders()`\nReturns array of initialized translation providers.\n\n#### `getSupportedLanguages()`\nReturns array of supported language codes and names.\n\n#### `clearCache()`\nClears the translation cache.\n\n#### `getTranslationMetrics(jobId)`\nReturns metrics for a translation job.\n\n## Configuration Options\n\n### TranslationOptions\n\n```typescript\ninterface TranslationOptions {\n  provider?: 'google-cloud' | 'deepl' | 'openai' | 'google-ai' | 'ollama';\n  targetLanguage: string;\n  sourceLanguage?: string;\n  style?: 'formal' | 'casual' | 'technical' | 'creative';\n  enableCache?: boolean;\n  culturalAdaptation?: boolean;\n  lengthOptimization?: boolean;\n  contextWindow?: number;\n  fallbackProviders?: string[];\n  glossary?: Record<string, string>;\n  maxRetries?: number;\n}\n```\n\n### SubtitleStyle\n\n```typescript\ninterface SubtitleStyle {\n  fontFamily?: string;\n  fontSize?: number;\n  color?: string;\n  backgroundColor?: string;\n  position?: 'top' | 'bottom' | 'center';\n  outline?: boolean;\n  shadow?: boolean;\n}\n```\n\n## Language Support\n\nSupported languages include:\n- English, Spanish, French, German, translation progress:\n\n```typescript\ntranslationService.on('translation:started', (job) => {\n  console.log(`Translation started: ${job.id}`);\n});\n\ntranslationService.on('translation:progress', ({ jobId, progress }) => {\n  console.log(`Progress: ${progress}%`);\n});\n\ntranslationService.on('translation:completed', (job) => {\n  console.log(`Translation completed:
